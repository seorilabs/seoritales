# 구매 안내와 첫 장면 미리보기

사용자의 2026-11-17 요청 「현재 10권까지 KDP, Google Play, APple Books에 제출해뒀는데 링크를 걸자. 그리고 콘텐츠 공개를 줄이자. 책 사서 볼 수 있도록 말이다」와 후속 선택 「첫 장면 + 그림 1장 (권장)」을 적용한다. 후속 선택에는 결말이 드러나는 해설과 질문 축소가 포함된다. 기존 승인된 웹 미리보기 설계의 화면 구조와 L1 개발 검증, 공개 끝 지점을 이어간다.

독자는 홈에서 책을 고르고, 책 페이지에서 서점을 선택한다. 첫 장면 미리보기는 보조 링크로 제공한다. 이야기의 첫 장면과 그림 한 장만 유지하고, 결말을 설명하는 추천 문구와 권별 질문은 공개 편집 데이터에서 제거한다. 교사용 안내는 주제와 읽기 시간, 일반적인 읽기 안내를 유지한다. 새 화면·시각 체계·의존성·출판 원고 변경은 없다.

2026-11-17 공개 HTTP 조회 결과 Apple·Google 1권 상품은 제목과 유료 Offer를 제공한다. 신규 9권의 Apple·Google 주소는 404이므로 활성 링크를 만들지 않는다. Amazon 10권의 기존 확인된 ASIN 링크와 Attribution을 유지하며, Amazon HTTP 로봇 확인 화면을 새 구매 검증으로 주장하지 않는다. Apple 링크는 공개 유료 상품과 웹 CTA 확인을 기준으로 연결하고 네이티브 앱 구매 확인·실제 결제·정산 완료와 구분한다. 가격을 사이트에 새로 표시하지 않는다.

출판 원본은 `Workspace/folktales`이며 미추적 사용자 파일을 보존한다. exporter 변경은 이 폴더의 `source-export.patch`로 보관하고 격리 실행한 생성 JSON만 반영한다. 기존 미리보기 정책과 비공개 이미지 제거는 유지한다. 실패한 서점 URL을 임의로 검색 링크나 다른 책으로 바꾸지 않는다.

AC-1: 10권의 첫 장면·그림 1장 외 본문, 문화 설명, 용어와 기존 권별 질문·결말 해설이 공개 HTML·JSON·JS에 남지 않는다. AC-2: 홈은 책 안내를 먼저 표시하며 미리보기의 구매 버튼은 모든 확인된 서점을 선택할 수 있는 책 페이지로 연결한다. 1권 Apple·Google 링크와 Amazon 10권 링크가 화면·구조화 데이터에 일치한다. 미공개 18개 주소는 노출하지 않는다. AC-3: 390×844와 1440×1000 실제 브라우저 실행, check·lint·정적 빌드·회귀 검사와 중앙 before-build/before-deploy를 통과하고 공개 결과를 확인한다.

실행 환경은 웹 브라우저 개발 환경이며 실기기 필요 항목은 없다. 링크·공개 범위 회귀를 먼저 실패시킨 뒤 구현한다. 편집 문구는 실제 렌더링과 비공개 내용 검색으로 확인한다. Ready PR, 로컬 코드 리뷰, 필수 검사와 중앙 검증 뒤 기존 GitHub Pages로 공개한다. 잘못된 링크는 해당 변경을 되돌리며 전문 공개 상태는 복구하지 않는다. 원시 HTML·로그·스크린샷은 NAS1dual에 해시 검증해 보관하고 저장소에는 요약과 경로만 남긴다.
