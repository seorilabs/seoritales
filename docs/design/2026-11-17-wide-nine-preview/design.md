# 10권 웹 미리보기 전환

2026-11-17 사용자의 「나머지 9권도 제출할수 있어?」 요청으로 최초 승인된 Apple·Google 확대 절차를 실행한다. 최초 계획의 웹 L1, 개발 환경, 기존 화면 구조 유지, 공개 배포 범위를 그대로 적용한다. 정산계좌 입력 보류도 유지한다.

권별 출판 원본의 `meta.web_publication.mode`를 `preview`로 설정하고 기존 exporter를 실행한다. 출판 원본과 KDP EPUB은 보존한다. 공개 데이터에는 첫 장면과 해당 그림만 남기며 문화 설명, 용어 풀이, 나머지 장면과 그림을 제거한다. 기존 미리보기 화면을 재사용하고 홈·소개·교사용 안내는 완전 공개 이야기가 0권인 상태를 정확히 설명한다. 공개 판매 확인 전 서점 링크를 노출하지 않는 조건을 유지한다.

인수조건 AC-1: 10권 모두 첫 장면만 공개하고 다른 본문과 이미지가 공개 HTML, JSON, JavaScript에 남지 않는다. AC-2: 홈·소개·교사용 안내와 SEO가 실제 공개 범위에 맞고 구매 확인 전 링크가 노출되지 않는다. AC-3: 390×844 및 1440×1000 개발 실행과 check, lint, 기존 테스트, 정적 빌드, 중앙 배포 검증을 통과하고 공개 결과를 확인한다.

본문 수정 없이 형식만 바꾼 EPUB은 EPUBCheck와 전 페이지 렌더링으로 별도 검수한다. 웹은 테스트 우선으로 10권의 미리보기 정책과 공개 이미지·HTML·번들 부재를 확인한다. 원본 이미지 품질과 서점 심사는 자동 웹 테스트로 대체하지 않는다.

새 화면·의존성·정산 변경은 없다. 기존 exporter와 데이터 규약을 재사용한다. 정적 검사 실패는 범위 안에서 수정하고, 공식 서점의 정책 거절은 원인을 별도 기록한다. 잘못된 공개는 해당 PR을 되돌려 복구하되 전문 공개를 복구하기 전 판매 중인 서점 상태를 확인한다. 원본 증적은 NAS1dual에 복사·해시 검증 후 보관하고 저장소에는 요약만 남긴다.
