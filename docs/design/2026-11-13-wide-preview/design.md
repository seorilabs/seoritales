# Apple·Google 판매 확대의 웹 미리보기

승인 근거: 2026-11-13 사용자가 제시한 「Seori Tales의 Apple·Google 판매 확대」 계획을 구현·검증까지 실행하라고 지시했다. L1, 개발 환경, 기존 화면 구조 유지, 웹 공개 배포까지가 승인 범위다. 법적 명의·계좌 재사용과 US$3.99, DRM 해제는 도서 판매 계획의 별도 승인에 따른다.

## 공개 흐름과 데이터

목록에서 『The Sun and the Moon』을 누르면 기존 이야기 화면에서 첫 장면의 그림과 글을 읽는다. 이어지는 안내는 그림책 구매 페이지로 연결한다. 나머지 9권은 양쪽 서점 파일럿이 완료될 때까지 기존 공개 범위를 유지한다. 새 화면이나 레이아웃 개편은 없다.

정본은 `folktales/books/*/book.json`의 `meta.web_publication.mode`다. `full` 또는 `preview`를 명시하고 Select 등록 중이면 더 좁은 첫 장면 공개를 적용한다. `pipeline/export_web.py`에서 공개 범위에 맞는 본문, 삽화, 문화 노트, 용어 풀이만 생성한다. 출력 폴더에 남은 그 책의 이전 삽화도 정리한다. 사이트 JSON을 수작업 수정하지 않는다. 기존 Amazon Attribution 링크는 보존한다.

새 서점 링크는 권별 원장의 `wide_stores`에 공개 구매 가능 상태, 확인 시각과 공식 상품 URL이 모두 있어야 내보낸다. 업로드·심사 상태로 링크를 노출하지 않는다. 사이트의 출간 도서 수는 확인된 판본 상태에서 계산하며 전문 무료 제공 수는 실제 공개 정책에서 계산한다. 읽기 시간은 원본 전체 이야기에서 계산해 미리보기의 짧은 분량과 혼동하지 않는다.

## 인수조건과 검증

- A1: 파일럿은 첫 장면만 공개한다. 이후 본문·alt·문화 노트·용어 풀이·삽화는 생성 JSON과 빌드의 HTML, JavaScript, 이미지 어디에도 포함하지 않는다. 출판 EPUB과 원본 텍스트는 보존한다.
- A2: Select를 해제해도 별도 `preview`가 유지되고, Select 등록 중에는 `full`도 첫 장면으로 제한한다. 후속권은 파일럿 gate 전 전문 상태를 유지한다.
- A3: Apple·Google 링크는 공개 구매 가능 확인 뒤에만 표시한다. 상태 조합의 회귀 검사와 기존 Amazon 판본·검색 검사를 통과한다.
- A4: 홈·소개·부모 교사 안내와 검색 설명의 공개 수, 제작 방식 고지가 사실에 맞고 작은 화면과 큰 화면의 기존 흐름이 작동한다.

데이터 차단은 실패하는 회귀 검사를 먼저 실행하고 최소 구현으로 통과시킨다. 문구·레이아웃은 정적 빌드와 390px·1440px 실제 브라우저로 확인한다. 실제 유료 구매와 모바일 기기 사용은 필요 없다. `npm run check`, `npm run build`, 기존 테스트와 lint를 실행한다. 생성 원본 패치는 이 폴더에 보존한다.

한국어 Ready PR, 로컬 MiniMax 코드 리뷰와 필수 검사 뒤 병합한다. 같은 최종 SHA의 개발 실행 근거를 중앙 검증기로 확인하고 Pages 명시 dispatch로 공개한 뒤 상품 링크·본문·미리보기 범위를 다시 읽는다. 실패하면 승인 범위의 수정 PR로 복구한다. 전문 공개로 되돌리기 전에 도서 판매·독점 조건을 확인해야 한다.
