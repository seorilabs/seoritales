# 구매 안내와 공개 범위 검증

작업: #11. 공개 서점 조회 요약과 원본 해시는 `store-readback.json`에 있다. Apple·Google 1권은 제목과 US$3.99 유료 Offer가 있는 공개 상품이다. 2–10권의 Apple·Google 주소는 404로 확인되어 활성화하지 않았다. Amazon 기존 10권 링크와 Attribution을 유지한다. 실제 결제·Apple 네이티브 구매 버튼·정산은 이번 웹 작업의 검증 범위가 아니다.

10권 모두 첫 장면과 그림 1장만 제공한다. 결말이 드러나는 편집 소개를 줄이고 권별 질문을 공개 편집 데이터에서 제거했다. 긴 서점 판매 소개도 공개 번들에서 제외하며 책 페이지와 검색 정보는 짧은 소개를 사용한다. 홈은 책 페이지를 먼저 연결하고 이야기의 구매 버튼은 서점을 고르는 책 페이지를 연다. 읽기 시간은 전체 책 기준이다. 공개 미리보기 정책이나 출판 본문은 변경하지 않았다.

검증은 `npm run check`, `npm run lint`, `npm run build`(회귀 검사 포함), 23개 경로의 390×844 및 1440×1000 브라우저 실행, 비공개 본문·이미지·기존 질문·해설의 산출물 누출 검색으로 수행한다. 최종 후보 SHA의 실제 결과는 GitHub의 `development-evidence` draft Release에 첨부한다. 자동 회귀는 Apple 링크 누락에서 먼저 실패했다.

원시 서점 HTML·로그·브라우저 화면·누출 검사 결과의 최종 보관 루트는 `/Volumes/Data/Backup/agent-artifacts/seoritales/2026-11-17/purchase-previews/`다. 복사 후 SHA-256을 대조하고 임시 원본·빌드·작업 폴더를 정리한다. 출판 원본과 사용자 기존 체크아웃은 보존한다.
